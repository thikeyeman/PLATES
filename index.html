Quick guide / 使い方

Edit the starter layers or use Clear canvas to start fresh. Add an object, edit it in Layers, and drag its canvas handles to resize or rotate. Change Font family in a text layer; select graphics on the canvas and press Delete to remove them. Open output, then use Take Live to broadcast a complete Preview snapshot. Clear Live clears only Program and turns realtime off. Realtime output broadcasts edits immediately; turning it off freezes Program. Play animations in Preview and Take Live while they run to continue them in Program. Video background is for the editor preview only; choose Chroma green for chroma-key capture or Transparent (alpha) for browser-source compositing. Export JSON for a portable backup. Reset animations restores objects to their positions and appearance before playback.
